# Productivity-Dashboard

A modern and aesthetic dashboard to track tasks, Pomodoro sessions, and daily productivity.

## Features
- Add, edit, and delete daily tasks
- Live weather info for any city 
-Changing background based on weather conditions 🌤️🌧️☀️
-Light/Dark mode toggle for a better user experience 🌑🌕
-Motivational quotes that refresh every time you visit
- Pomodoro timer for focused work
- Track daily goals and achievements
- Clean and interactive user interface
